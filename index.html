Dream Machine v2.0

Dream Machine v2.0 is a browser-based generative system that operates on existing images over time.
Field-based agents apply local drift, color mutation, and pixel zoom, continuously reshaping the image. At irregular intervals, regions from the original source are sampled and reinjected at new positions using organic, feathered masks.

An ongoing project by Niklas Wallenborg exploring machine-human creativity through post-digital aesthetics.
