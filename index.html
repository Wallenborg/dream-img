Dream Machine v2.5

Dream Machine v2.5 is a browser-based generative system that transforms existing images through autonomous, field-based agents.
Local drift, color mutation, and pixel displacement continuously reshape the image, while fragments from the original source are intermittently sampled and reintegrated using organic, feathered masks. The system monitors its visual distance from the source material and concludes each process when a unique internal threshold is reached, then ends the dream.

An ongoing project by Niklas Wallenborg exploring machine-human creativity through post-digital aesthetics.
